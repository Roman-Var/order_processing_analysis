# Пет-проект системного аналитика: анализ процесса заказа еды

Заказ еды в одном ресторане: от телефонных звонков к приложению. Скоуп — одно заведение, не агрегатор.

- **As-is** — заказ по телефону, только самовывоз, оплата на месте.
- **To-be** — приложение ресторана: доставка через курьерскую службу, онлайн-оплата или оплата при получении, бронирование курьера в момент начала готовки.

Инструменты: Camunda Modeler 5.x, BPMN 2.0.
